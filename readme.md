# Smart Dine In System Setup

Follow these steps to run the project locally.

## 1. Create environment files

Create a `.env` file in both folders:

- `smart_dine_in/`


## 2. Install dependencies

In both folders, run:

```bash
npm install
```

## 3. Start the apps

### Frontend

```bash
cd client
npm run dev
```

### Backend

```bash
cd smart_dine_in
npm run dev
```

## 4. Notes

- Make sure both apps are running for the full system to work properly.
- Make sure you have the .env file in the smart_dine_in folder(Ask me to send it to you)
